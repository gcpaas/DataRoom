# 热力图

在组件库“热力图”分类中拖入组件，绑定数据集和 X 轴类目、Y 轴类目、格子数值三个字段。

数据集使用对象数组，例如：

```json
[
  { "hour": "08:00", "day": "周一", "value": 0 },
  { "hour": "12:00", "day": "周一", "value": 35 }
]
```

- 在“格子”中设置背景色、分段数、最小值和最大值。默认范围 0～100，分为 5 段，透明度依次为 20%、40%、60%、80%、100%。背景色的透明度由分段计算，不叠加输入色的透明度。
- 区间左闭右开，最后一段包含上限；低于最小值按首段、高于最大值按末段显示，标签保留原始数值。范围不随数据或主题变化，色标固定隐藏。
- 新建组件默认边框宽度为 0、标签字号 14px 且为白色，示例为 5×5 共 25 个格子，各数值区间在横纵方向交错分布。
- 旧组件自动迁移原有数值范围，以原颜色列表首色作为背景色，保留已有边框和标签设置。
- X、Y 轴名称均支持独立设置字号和颜色，不影响类目标签样式。
- 类目默认按首次出现顺序排列。配置类目列表后，该列表限定完整轴范围和顺序；列表外记录不显示。
- 数值 0 正常显示；null、空字符串、非数值不绘制。数值字符串可转换为数值。
- 同一 X/Y 坐标保留第一行，包括该行数值缺失时；需要聚合请在数据集 SQL 或数据处理脚本完成。
- 未绑定数据集时提供示例；绑定数据集后，空结果不会回退为示例数据。
- 点击格子输出 x、y 类目文本及 value 原始数值。
- 动画使用独立折叠面板；全局配置仅设置边距。
